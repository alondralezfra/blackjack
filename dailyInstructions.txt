# :black_joker: Final Homework: MERN Full House
This is your final assignment before we head into break — and it's all about connecting the dots.
You’ll be building a multi-level MERN app that ties together:
Node.js + Express (Backend)
MongoDB + Mongoose (Database)
React (Frontend)
API Integration
---
## :dart: Purpose
This is *not meant to be a finished, polished product*.
Instead, think of it as a *technical checkpoint* to make sure you understand how the backend, frontend, and database connect and work together. When we’re back from break, you’ll start a full project — this will prepare you for that.
This homework is just the warm-up — make sure you understand how the parts fit together.
It’s okay if it’s not complete. Just try your best to *connect the stack*.
---
## 🃠 Theme: Blackjack... or Anything You Like
We've used Blackjack throughout the course — this is a great chance to evolve that into a full MERN app.
But: *you’re free to do something else* if you’d rather build a todo app, blog, movie tracker, or anything that uses similar structures. Just follow the level structure below.
---
## :package: Level 1 – Backend Bootup
*Goal:* Set up a basic Express server
### Requirements:
Create an Express server
Implement at least 2 routes (GET, POST)
Send/receive JSON
Use nodemon for development
Test with Postman or Curl
:dart: Blackjack Tip: Make a route to start a game or return a shuffled deck.
---
## :card_file_box: Level 2 – Database Connection
*Goal:* Add MongoDB with Mongoose
### Requirements:
Create at least one model (Game, Player, Session, etc.)
Save and retrieve data from MongoDB (local or Atlas)
Implement full API interaction (GET, POST, DELETE)
:dart: Blackjack Tip: Store hands, games, or user sessions.
---
## :globe_with_meridians: Level 3 – React Frontend
*Goal:* Build a basic frontend to consume your API
### Requirements:
Set up a React app
Fetch data from your backend
Display and submit data via forms or buttons
:dart: Blackjack Tip: Show cards, start a game, display win/loss.
---
## :zap: Level 4 – Full Integration
*Goal:* Connect everything into a working full-stack app
### Requirements:
Full CRUD integration between frontend/backend
Forms to create/edit/delete data
Working API and database functionality
Basic UX (loading/error states, feedback)
:dart: Blackjack Tip: Implement hit/stand logic via buttons, show game history.
*Bonus:*
Deploy frontend (Netlify/Vercel) and backend (Render/Heroku)
Add authentication (JWT/session)
Use global state (Context API / Redux / Zustand)
